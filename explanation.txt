1. Face Detection & Alignment
Detect face region
Align it (straighten eyes, nose)
Tilted Face → Straight Face

*It Makes processing easier

2. Latent Space (Very Important Concept)

Latent space = compressed face knowledge

Think of it like:
Face → Code (numbers representing face features)

Example features:
eye distance
nose shape
face structure

3. Prior Face Knowledge

GFPGAN is trained on millions of faces.

So it knows:
how eyes should look
how lips should form
how skin texture behaves

It doesn’t just enhance
It reconstructs

4. GAN Again (Generator vs Discriminator)

Same idea as RealESRGAN:
Generated Face vs Real Face
Keeps output realistic
